## 阿什本在哪，为什么国内访问普遍在 220ms 以上

阿什本（Ashburn）在弗吉尼亚州劳登郡，华盛顿特区以西约 30 英里，是美国东海岸数据中心最密集的区域之一。位置决定了它到中国大陆的物理距离，也决定了延迟的下限。

几家测评的实际数据可以拼出一个区间：

- RackNerd 阿什本测试机，国内平均延迟约 **220ms**，部分地区有丢包，三网基本直连不绕道；
- IPRaft 阿什本双 ISP 套餐，国内平均延迟 **278ms**，移动回程甚至绕英国；
- IPRaft 阿什本单 ISP-ATT 套餐，国内平均 **271ms**，测评作者的原话是“一般美国东部机房也就 220ms 左右的延迟”，言下之意 271ms 已经偏高；
- Gcore 阿什本 2022 年的测试里，上海电信 215ms、厦门电信 273ms、重庆联通 257ms、上海移动 247ms。

把这几组数放在一起，美东机房的合理预期就是 **220ms 上下**。超过 270ms 说明线路在美国国内段或者回程绕了路，不是机房本身的问题，是路由选择的问题。所以看到某家阿什本套餐标称“直连”，先别急着信，延迟数字比“直连”两个字有用。

对中国用户来说，220ms 意味着网页首屏能感觉到停顿，SSH 敲命令有肉眼可见的延迟，视频会议和实时操作基本别想。这也是为什么做国内生意的站，同行普遍推荐洛杉矶和西雅图，而不是阿什本。
